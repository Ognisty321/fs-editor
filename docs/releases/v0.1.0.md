The first release of FS Editor: an ASS/SSA subtitle editor with Aegisub's logic and automation API and Kainote's layout.

## Highlights

- Lossless ASS: a file opened and saved without changes is byte-for-byte identical.
- Frame-exact video, audio with a waveform and spectrogram, visual typesetting tools on the video, and Kainote's translation mode.
- Aegisub Automation 4 scripts in Lua and MoonScript, checked against Aegisub 3.5's sources.
- A pre-release review fixed about 40 bugs and cut typing, grid and undo latency by half or more on a 50,000-line file.
- Audio appears in the window as soon as its index is read and decodes in the background: 0.1 s instead of 39 s on a 23 GB remux.

## New

- **Formats.** Lossless ASS. ASS, SSA, SRT, MPL2, MicroDVD, TMP and TTXT with encoding detection; export to EBU STL, Encore and TranStation.
- **Video and audio.** Frame-exact video (BestSource, VFR, keyframes, chapters, libass preview) and audio with a waveform, a spectrogram and a karaoke mode.
- **Visual tools on the video.** `\pos`, `\move`, `\org`, `\clip`, `\p` drawings, scaling and rotation.
- **Timing.** Timing tools, the timing post-processor, the kanji timer, frame rate change and resolution resampling.
- **Translation mode** compatible with Kainote's.
- **Automation.** Aegisub Automation 4 scripts in Lua and MoonScript.
- **Tools.** Style manager, fonts collector, spell checking, find and replace, autosave.
- **Interface** in Polish and English.

## Improved

### Performance

Measured on a 50,000-line file (window) and a 100,000-line file (core):

| Operation | Before | After |
|---|---|---|
| a character typed in the text box | 11.0 ms | 5.0 ms |
| showing the change in the grid | 9.7 ms | 3.5 ms |
| changing the active line | 8.7 ms | 4.6 ms |
| undo | 4.9 ms | 0.3 ms |
| saving 100,000 subtitles as SRT | 270 ms | 165 ms |

The window no longer repaints itself whole after every key, the grid lays out a cell's text once, and "Save the file after every change" no longer checks the file format on every key. Everything else was already fast and stayed as it was: opening 100,000 lines 70 ms, a key in the core 0.3 ms, saving ASS 71 ms, reading all 50,000 lines from a Lua script 97 ms.

### Aegisub API compatibility

Behaviour was compared with Aegisub 3.5's sources and corrected wherever it differed:

- `aegisub.version` exists, and API errors point to the place in the script, as in Aegisub.
- `subs["7"] = line`, `subs:delete(i)` and `ipairs(subs)` work as in Aegisub.
- Style colours go through the same grammar (`#RRGGBBAA`, `-1`, hex without `H`); commas in style and font names become semicolons.
- A dialog returns the values of all its controls in order, including unnamed ones (under `""`); a dropdown whose value is not one of its items returns `""`.
- `aegisub.project_properties()` reports the current line, scroll position and video frame rather than the state at the last save; macro validation functions see the audio selection.
- `aegisub.re`: no more "JIT stack limit reached" errors on long lines, plus the missing parts of Boost's syntax (`\l \u \L \U`, long Unicode category names, `$+{name}`, `$MATCH` and its relatives).
- `lfs.attributes` follows symbolic links, `lfs.rmdir` on a path that does not exist is not an error, and `lfs.touch` creates directories.

### Audio and video loading

Measured on a 24-minute episode (1080p, AAC) and a 23 GB remux (DTS-HD MA), with BestSource R23 instead of R22:

| Operation | Before | After |
|---|---|---|
| episode audio shown in the window (file already indexed) | 1.4 s | 0.2 s |
| episode audio fully decoded | 1.4 s | 1.3 s |
| remux audio shown in the window (file already indexed) | 39 s | 0.1 s |
| remux audio fully decoded | 39 s | 24 s |
| 10 minutes of TrueHD | 119 s | 2.8 s |
| 10 minutes of DTS | 1.4 s | 0.7 s |
| stepping back three frames before the video index is finished | 187 ms | 30 ms |

Audio is in the window right after its index is read and decodes in the background, like Aegisub's RAM cache: the waveform and spectrum fill in as it goes, the status bar shows progress, and whatever is not decoded yet plays as silence. A long track is decoded in several parts at once where the codec allows seeking; where it does not (DTS-HD MA), one decoder runs through it from start to end instead of several waiting on each other. The samples are exactly the same as before (compared on 70 and 258 million samples).

## Fixed

The pre-release review of the whole codebase fixed about 40 bugs, among them:

- Three crashes in the core (splitting a line whose end is before its start, `\kt` going backwards in karaoke, an audio slice past the end) and two in export (EBU STL at 100 hours or more, characters not allowed in XML in TTXT).
- Font data in `[Fonts]` that looks like a section header is no longer taken for a new section.
- Format conversion keeps comments, Project Garbage, Extradata and unknown sections.
- A deadlock in a Lua script whose line table itself reads `subtitles`, and in a script that uses the clipboard while loading.
- `fsed` saves MicroDVD at the frame rate it was loaded with, and does not save a file under another format's extension.
- In the window: a new video brings its own audio, as in Aegisub; "Cancel" in the colour picker undoes only its own preview; the Move and position-shift tools write nothing on a plain click; font settings are saved only after OK.

## Known limitations

- A few minor differences from Aegisub were kept on purpose, with no effect on scripts: the wording of some error messages, `\N{name}` and `[[.x.]]` collating elements in `aegisub.re`, and LPeg 1.1 instead of 0.10.
- The first time a file is opened, BestSource still indexes it first, as in Aegisub; the index is kept on disk.
- macOS is not built or tested yet.

## Install

Unzip the package anywhere and run `bin/fsed` (`bin\fsed.exe` on Windows); there is nothing else to install. Inside are:

- the program with the Qt, FFmpeg, BestSource and libass libraries;
- Aegisub's automation scripts (`bin/automation`): karaskel, kara-templater, the autoload macros and the include modules;
- Hunspell spelling dictionaries and thesauri for Polish and English (`bin/dictionaries`), each with its licence files;
- `LICENSE` and `THIRD_PARTY.md`.

The packages were built by CI from the tagged commit; verify a download against `SHA256SUMS.txt`.
